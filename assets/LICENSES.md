# Blackbriar asset credits

## Original artwork

`library.png`, `author_atlas.png`, and all 59 illustrations in `cards/`: generated for Blackbriar using OpenAI image generation. These are newly generated illustrations, not historical portraits or reproductions of source-book artwork. No third-party stock images were used in these assets.

## Original audio

`ambience.wav`, `click.wav`, `play.wav`, `clash.wav`, and `victory.wav` were synthesized specifically for this project using the original, deterministic Python program `tools/generate_audio.py`. They contain no sampled recordings or external music. Audio is 22,050 Hz, 16-bit mono PCM. The ambient composition is 12 seconds and phase-continuous when looped. Original project audio can be used and modified with this game.

## Literary content

Card rules, lesson summaries, and question explanations were written for this game. The named source works by Edgar Allan Poe, Mary Shelley, William Shakespeare, Jane Austen, and Lewis Carroll are public-domain literary works in the United States. Work titles and approximate composition dates appear in card metadata. Character abilities are game interpretations, not claims that the characters possess those powers in the source texts.
